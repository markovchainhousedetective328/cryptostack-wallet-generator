## 🔐 Why offline is safer

Computers connected to the internet face risks from malicious software and hackers. By running this tool offline, you remove the link between your private keys and the web. The code stays on your hard drive. It never sends data to a server. You maintain total control over your digital assets. 

## 📝 Features

*   **Deterministic generation:** The tool creates the same wallet every time you provide the same seed phrase. This helps you recover access if you lose your device.
*   **Zero dependencies:** The software contains all required code in one file. You do not need to install external libraries or updates.
*   **Vanity addresses:** You can generate wallet addresses that start with specific letters or numbers. This adds a personal touch to your public address.
*   **Privacy:** The application generates all data locally within your browser memory.

## 💡 Best practices for your seed phrase

Your seed phrase serves as the master key to your funds. If you lose this phrase, you lose access to your money. If someone else sees this phrase, they can take your money. Follow these rules to protect your assets:

*   Write the phrase on paper. Keep the paper in a fireproof safe.
*   Do not take a photo of the phrase.
*   Do not store the phrase on a cloud service like Google Drive or iCloud.
*   Do not type the phrase into any website other than this offline tool.
*   Check your spelling carefully when you write down the words.
